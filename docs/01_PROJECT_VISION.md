# Nova — Project Vision

## What is Nova?

Nova is a small, expressive programming language designed to
explore how programming languages work from source code to execution.

## Goals

- Simple and readable syntax
- Lexer and recursive-descent parser
- Source-aware AST
- Tree-walking interpreter
- First-class functions
- Closures
- Interactive REPL
- Helpful error messages
- Experimental bytecode virtual machine

## Long-Term Vision

Nova aims to grow from a small language experiment into a
well-documented, testable and extensible programming language.

## Current Status

Nova is in early development.
